# Инструкции для ИИ-агента (AGENTS.md)

## 1. Назначение проекта
Мини-бэктестер торговой стратегии SMA-crossover на C++. 
Программа читает исторические данные о ценах, генерирует торговые сигналы на основе пересечения скользящих средних, симулирует исполнение сделок по правилу "next open" и рассчитывает метрики эффективности (PnL, Total Return, Max Drawdown, Sharpe Ratio).

## 2. Структура проекта
- `include/backtest/` — публичные заголовочные файлы (API).
- `src/` — исходный код (sma.cpp, backtester.cpp, metrics.cpp, main.cpp).
- `tests/` — unit-тесты с использованием фреймворка doctest.
- `benchmarks/` — бенчмарки с использованием Google Benchmark.
- `.github/workflows/` — конфигурация CI/CD.

## 3. Основные команды
- **Сборка:** `cmake -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build`
- **Тесты:** `ctest --test-dir build --output-on-failure`
- **Бенчмарк:** `./build/bench_backtest`
- **Запуск CLI:** `./build/backtest_cli`

## 4. Правила оформления кода
- Язык: C++17.
- Стиль: Google C++ Style Guide (отступы 2 или 4 пробела, camelCase для функций, PascalCase для типов).
- Все сущности должны находиться в пространстве имен `backtest`.
- Публичные функции и классы обязательно должны иметь Doxygen-комментарии (`/** ... */`).

## 5. Ограничения и правила для ИИ-агента
- **Обязательная проверка:** перед завершением любой задачи (генерации кода) ты ОБЯЗАН собрать проект и запустить тесты (`ctest`). Если тесты падают — исправь код.
- **Запрет на CI/CD:** не изменяй файлы в `.github/workflows/` и `CMakeLists.txt` без явного запроса пользователя.
- **Зависимости:** не добавляй новые сторонние библиотеки без согласования.
- **Безопасность:** не используй сырые указатели там, где можно использовать `std::vector` или умные указатели.
